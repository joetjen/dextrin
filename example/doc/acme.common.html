acme.common

Types every Acme service shares.

This is a namespace file: each entry is acme.common/<Name>, and any other schema refers to one by that full name, for example acme.common/Money. Keep this file small and stable -- a change here reaches every service at once.

Address

struct schemav1

acme.common/Address

A postal address.

  • lines holds the street and house number, one per line, at most three.
  • country decides how the rest is read: a postcode is required for most countries but not all, so it is optional here.
#FieldTypeNotes
1 lines {:refine {:list-of NonEmptyString} %{min-count: 1 max-count: 3}}
2 city NonEmptyString
3 postcodeoptional :string
4 country CountryCode
5 kind {:enum :home :work :billing :shipping}
default :home

What the address is used for.

Money

struct schemav1

acme.common/Money

An amount of money in one currency.

The amount is exact: always write it as a decimal (19.99M), never as a float. Two amounts are only comparable in the same currency.

#FieldTypeNotes
1 amount :decimal

never a float
2 currency CurrencyCode
3 exchange_rateoptional :rational

The rate used when the amount was converted from another currency, as an exact ratio: 1095/1000 for 1.095.
