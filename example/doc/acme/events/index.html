Namespace

acme.events

The events Acme's services publish on RabbitMQ.

Every message is an Envelope. Its type names the event, and the event decides what the payload looks like: the payload types below are shapes -- plain maps with known keys -- not structs, so a consumer in any language reads them as maps.

To add an event:

  1. Add a shape for its payload here.
  2. Add its type to EventType and to the payload case in Envelope.
  3. Publish it; a consumer that does not know the type skips it.

A customer registered.

The payload carries the id and the country only: an event is no place for personal data (see acme.shop/Customer).
