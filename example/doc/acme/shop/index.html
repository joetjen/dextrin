acme.shop/Customer

Someone who buys from Acme.

Personal data: everything here except id falls under the data protection rules. Never log a customer, and never put one in an event payload in full -- use id.

The current version of a customer.

Version 2 only appends fields to version 1, so an older reader of the binary form still finds every field it knows in the same position.

acme.shop/Order

One purchase by one customer.

An order, kept in a directory of its own: acme/shop/Order/vN.dxns holds version N of acme.shop/Order.

The other entries in this file -- OrderLine, Status, Quantity -- are internal to it: Order uses them, and no other schema can, because no file name leads to them.
